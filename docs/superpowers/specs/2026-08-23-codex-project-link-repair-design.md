# Codex 项目关联修复工具设计

## 目标

提供一个可重复运行的 Windows GUI 工具，审计并修复 Codex 聊天与本地项目之间丢失或不一致的索引关联。

## 边界

- 同步 `~/.codex/.codex-global-state.json`、其 `.bak` 文件及 `~/.codex/state_5.sqlite`。
- 不修改聊天正文、标题、归档状态、父子会话边或项目源码。
- 默认只审计。修复前必须生成可恢复备份。
- 仅自动处理证据明确的关联：已有显式 JSON 关联，或未标记为 projectless 且工作目录唯一匹配一个项目根目录。
- 显式 projectless、多个项目根目录均匹配、目录不存在或证据冲突的记录不自动关联。

## 用户界面

WinForms 窗口包含状态摘要、异常表格、日志区域，以及“审计”“保守修复并重启 Codex”“恢复最近备份”三个按钮。表格显示聊天 ID、标题、工作目录、当前项目、建议项目和原因。

## 数据流

审计读取 JSON 与 SQLite，规范化 Windows 路径后生成报告。修复先备份 JSON、SQLite、WAL、SHM，再关闭 Codex，等待进程退出，事务性同步项目、根目录和明确的聊天关联，运行同一套审计断言，最后重新打开 Codex。

## 错误处理

JSON 解析失败、SQLite 架构缺失、备份失败、Codex 未完全退出或验证失败时停止写入并显示错误。SQLite 使用事务；JSON 使用同目录临时文件后原子替换。恢复操作只接受工具生成且清单完整的备份。

## 发布标准

仓库包含许可证、README、版本号、测试、构建脚本、SHA-256 校验文件和可直接下载的 ZIP。Release 前必须通过夹具测试、语法检查、干净环境 smoke test、ZIP 内容检查和校验和复核。
